## 香港醫療系統 - 用戶需求分析

### 一、用戶畫像（Personas）

#### 1. 普通市民（General Public）
- **需求**: 搵附近診所、查醫生資料、了解收費
- **搜索行為**: 「睇邊個醫生好」、「感冒睇咩科」、「近我屋企嘅診所」
- **關鍵詞**: 地區、專科、收費、診所開放時間、是否接受醫療券

#### 2. 長期病患者（Chronic Patients）
- **需求**: 專科門診輪候時間、藥物名冊、覆診安排
- **搜索行為**: 「糖尿病專科輪候時間」、「公立醫院排期幾耐」、「藥物名冊」
- **關鍵詞**: 專科、輪候時間、醫院、藥物

#### 3. 家長（Parents）
- **需求**: 兒科服務、疫苗接種時間表、母嬰健康
- **搜索行為**: 「BB打針時間表」、「邊間醫院有兒科」、「兒童急症」
- **關鍵詞**: 兒科、疫苗、母嬰健康院、急症

#### 4. 長者（Elderly）
- **需求**: 長者健康服務、醫療券、社區照顧
- **搜索行為**: 「醫療券邊度用得」、「老人科」、「長者健康中心」
- **關鍵詞**: 醫療券、長者、老人科、社區健康

#### 5. 遊客／新移民（Tourists / New Immigrants）
- **需求**: 英文醫生、私家醫院、保險覆蓋
- **搜索行為**: "English speaking doctor", "private hospital", "travel insurance"
- **關鍵詞**: English, private, insurance, 24hr

### 二、核心搜索維度

| 維度 | 說明 | 示例 |
|------|------|------|
| 地區 | 18區篩選 | 中西區、油尖旺、沙田 |
| 機構類型 | 公營 / 私營 | 醫管局、私家醫院、私家診所 |
| 服務類型 | 服務分類 | 急症、專科門診、普通科、牙科、中醫 |
| 專科 | 醫療專科 | 心臟科、兒科、婦科、骨科、眼科 |
| 語言 | 診症語言 | 廣東話、普通話、英文 |
| 收費 | 費用範圍 | 免費（公營）、$200-$500、$500+ |
| 營業時間 | 開放時間 | 24小時、夜診、星期日開診 |
| 醫療券 | 是否接受 | 接受 / 不接受 |

### 四、搜索功能設計

#### 4.1 即時搜索（Quick Search）
- 輸入關鍵字即時顯示結果（如「心臟科 旺角」）
- 支援中英文混合搜索
- 自動補全（autocomplete）

#### 4.2 篩選式搜索（Faceted Search）
- 多維度同時篩選（地區 + 類型 + 專科）
- 篩選結果即時更新數量
- 支援手機上滑動篩選

#### 4.3 地圖搜索（Map Search）
- 基於地理位置顯示附近醫療機構
- 點擊地圖標記查看詳情
- 支援路線規劃

#### 4.4 常見問題快速入口
- 「傷風感冒睇咩科？」
- 「邊間急症室最近？」
- 「星期日邊度有醫生睇？」

### 六、用戶體驗原則

1. **最少點擊原則**: 用戶應在 3 次點擊內找到所需資訊
2. **手機優先**: 60%+ 用戶在手機上搜索醫療資訊
3. **中英雙語**: 支援中英文搜索及顯示
4. **即時性**: 急症室輪候時間等關鍵數據應盡量即時
5. **可信任**: 所有資料標明來源及更新日期
